# Аналитический слой магазина

Проект построен на dbt и Greenplum. Составляется аналитический слой для интернет-магазина: сырые данные из OLTP-базы преобразуются в витрины по схеме «звезда».

## Устройство проекта

1) Staging - очистка данных (переименование, приведение типов);
2) Intermediate - промежуточные шаги (JOIN-ы, агрегации);
3) Marts - готовые витрины для аналитиков (факты, измерения).

## Вопросы бизнеса

- выручка по месяцам и категориям товаров;
- доля покупателей по каналам привлечения;
- средний чек по городам;
- возвраты по брендам.

## Схема «звезда»

- факты: `fct_orders`, `fct_order_items`.
- измерения: `dim_customers`, `dim_products`, `dim_dates`.
